# List 参考卡

## 来源与证据

- Arc 2026-10-26 的公开 `llms.txt` 数据列表中没有独立 `List` 组件；Data 组包含 `Pagination`、`Card`、`Tree view` 等条目。
- 本组件因此采用 WPF `ListBox` 原生行为，视觉参数沿用 Arc 语义令牌和已冻结的 TreeView 行布局经验。
- 来源用途：设计语言参考；没有复制上游代码或素材。

## 主示例

Gallery 使用三行列表：标题、说明、长文本省略和禁用项，列表容器高度固定以验证滚动。

## 待验收

实际窗口中检查点击、键盘焦点、滚动条、主题切换、长文本省略及 100%/150%/200% DPI。
