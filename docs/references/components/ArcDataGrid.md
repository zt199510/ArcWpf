## 状态与动效索引

- 有截图和 DOM 证据：初始、表头/行/序号悬停、排序（升/降/多列）、框选、滚动（右/下）、密度、筛选（打开/输入/无结果）、搜索、批量（单选/全选）、编辑、非法值、分组（一层/折叠/两层）、固定列、删除、深色。
- 只有行为观察、参数为推测：行滑动、闪烁、状态消息时长、工具栏切换、抖动。Arc 的动效实现不可见，详见规格“视觉与动效”。
- 行为结论（运行观察）：选区是数据行的位置而非行身份，排序/分组/折叠后地址不变；单个单元格只显示 Count，多于一格才有 Sum/Average；无结果时状态栏显示 `–`；Reset 只跟随数据是否与初始不同，视图变化不启用它，撤销回初始后恢复禁用。

## WPF差异和回归入口

- 允许差异：字形来自 Segoe UI 回退（Wine 下为 Liberation），Arc 为 Inter；Medium 字重与 -0.14px 字距无对应。文字宽度差会使搜索框这类伸缩元素相差数像素。
- 有意不还原的上游缺陷：① 空状态 “Clear filters” 按钮宽度被压成 32 的圆，文字溢出，WPF 用完整胶囊；② 横向滚动时筛选输入浮在固定列之上，WPF 裁在固定列下方。
- 回归：`tests/ArcWpf.Tests/ArcDataGridTests.cs`；记录见 [验证记录](../../verification/2026-11-03-data-grid.md)。
