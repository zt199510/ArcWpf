## 已确认的重要结论

| 对象 | 源码或文档证据 | 对 WPF 的影响 |
|---|---|---|
| Button | primary/secondary/ghost/danger，sm/md/lg；主样式是 foreground/background | 不默认把主按钮改成强调色 |
| Button 加载 | loading 保持焦点并抑制点击；禁用是另一状态 | IsLoading 不能简单等价于 IsEnabled=false |
| Input | 专用属性为 label、description、error；其余透传原生 input | 不把前后缀当作原版已有 API；需要时记为扩展 |
| Switch | 轨道 42×24px、内边距 3px、滑块 18px、位移 18px、按压伸长 5px | 先按 CSS px 到 WPF DIP 的设计映射实现，实际显示待验 |
| Switch | 位移 glide 为 visualDuration=0.3、bounce=0；宽度使用 snappy=0.26 | 不能用一个通用 snappy 参数替代全部运动 |
| Popover | align=start、sideOffset=6、collisionPadding=10 | 宿主选择需保持间距与边界行为 |

精确文件见四份组件规格及 [公共基础](foundation-motion.md)。所有运行效果仍待观察，源码结论不等于网站运行验证。

## 已发现的冲突

1. Popover 文档写退场 140ms，但 CSS 引用 duration-fast，foundation 定义为 160ms。暂以冻结源码 160ms 为移植参数，保留文档冲突，实际运行待核对。
2. Switch 文档称运动为 CSS transitions、没有逐帧工作；源码明确使用 motion.span、useMotionValue 和 animate。不能据文档得出运行成本结论，WPF 必须测量。
3. Button 文档概括按压为 snappy spring，源码按下分支指定 instant=0.12s 的过渡，恢复使用 snappy。按下与恢复应分别设计。
