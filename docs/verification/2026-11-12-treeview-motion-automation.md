# 2026-11-12 TreeView 行动效、图标与 AutomationPeer

状态：**实现完成，待验收**。范围：补齐 2026-11-11 核对时发现的首版缺失项（规格曾标为已实现，代码里没有）。规格见 [TreeView](../components/TreeView.md)，来源为冻结的 `2026-10-26-tree-view`。

## 改了什么

- 可见行改为稳定对象并增量更新：保留下来的行不再重建容器，所以能做进入/退出动画，悬停和键盘焦点也不再因选择或展开而丢失。超过 256 行同时变化或子项顺序改变时仍整体换入（与 2026-11-11 的虚拟化一致）。
- 新增公开的 `TreeViewRow`（默认行模板的根）：悬停/选中颜色、Chevron 旋转、文件夹图标切换，以及 TreeItem 自动化。
- 树负责：子项进入（高度、淡入、左移、按打开的文件夹逐项延迟）、退出（折叠后移除）、退出中再展开时长回、选中底色在行间滑动、分支线绘入。
- 外形：行与选中底色改为整行宽，深度只缩进内容；分支线每层都画（此前只有第 2 层）；FolderOpen 图标；文件类型色（主题按 CSS oklab 混合计算）；悬停底色；选中标签为前景色；禁用节点 0.45 不透明；自定义 `Icon` 此前不显示，已修正。
- AutomationPeer：树为 Tree + Selection，行为 TreeItem + ExpandCollapse + SelectionItem，带同级位置与数量；展开、选中变化时发属性变更事件，行变化时 `InvalidatePeer`。

## 与来源的差异

- 文字和文件夹图标的颜色过渡用两层交叉淡化实现，中点颜色与 CSS 颜色插值略有差别；终态一致。
- WPF 不提供 UIA Level，`aria-level` 没有对应；同级位置/数量已提供。
- 禁用态外观来源没有，沿用规格的“降低不透明度”。
