## 截图对照

每个状态都重新加载 Arc 公开预览，用相同操作进入，页面小数偏移已对齐到整像素；WPF 使用同样数据和状态。结果在 `artifacts/data-grid-2026-11-03/`（`final.txt`、`cmp/`）。

| 指标 | 28 个状态范围 |
|---|---|
| 差值 >32 的像素占比 | 1.7%–6.0% |
| 任意差值的像素占比 | 5.4%–13.5% |

**结论：不是逐像素一致。** 程序列出的 5×5 以上实色差异区只剩三类：文字字形；由文字宽度带来的搜索框右缘偏移；工具对照的焦点差（`search-typed` 中 Arc 搜索框有焦点）。尺寸、线条、取色、图标路径和状态内容已逐项对上。字体差异在本环境尤其明显，这里的 Segoe UI 实为改名的 Liberation。
