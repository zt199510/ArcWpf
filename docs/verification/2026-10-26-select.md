# Select 实现与验证（2026-10-26）

状态：代码及程序化验证完成，待实际窗口用户验收。Windows x64、SDK10.0.402、net10.0-windows、Release。遵循既定延期，本次没有显示测试窗口、截图或实际交互观察。

## 完成范围

Select继承ComboBox，SelectItem继承ComboBoxItem；Label/Description/Placeholder、ItemsSource及SelectedItem/Value/ValuePath/DisplayMemberPath、禁用、原生自动化。不可编辑。默认项及普通文本使用省略号；自定义ItemTemplate保留原生ContentPresenter，跳过文本快照过渡。

菜单采用PART_Popup，逻辑IsDropDownOpen与实际IsPresented分离，关闭时保留120ms退出；关闭后的命中立即禁用，重开有代次保护。与原生ComboBox捕获、选择、高亮和焦点机制协作；Owner失活/关闭、锚点无效、卸载/换模板清理。定位复用Popover已有屏幕/工作区辅助与纯定位计算：间距4、碰撞留白12、宽跟随触发器、最高320，空间不足翻转/夹紧。

实现触发器颜色、箭头旋转、文本方向滚动/模糊、菜单进退场、项高亮颜色及勾号动画。OwnedMotion增加可选完成回调、延迟和进入曲线，原调用默认行为保持；时钟清除后保留内部基值。真实选择由ComboBox自动化暴露；旧值SelectSnapshot不创建AutomationPeer。

Gallery的Team示例：Design初选，Engineering、Research；说明Choose the team that owns this work.，最大540宽。扩展占位、禁用项/字段、对象数据绑定、长列表/长标签及RTL。Consumer同步并加入滚动容器，避免组件增加后被窗口裁剪。

## 差异与待验收

原版28px上下滚动按钮替换为WPF滚动条；宽度以触发器同宽优先，工作区不足才缩小（CSS的min-width可能压过384px max-width）；保留系统字体回退及单层主阴影。默认矢量图标为项目自主绘制，不分发Lucide资产。自定义项模板不滚动旧文本快照，直接显示真实模板内容。

方向键/Enter/Escape/Tab及文本前缀搜索沿用ComboBox，另补关闭时Enter/Space/Down打开和打开时Space提交；保留关闭状态原生Up/Home/End行为。源站非编辑选择与WPF不完全相同，不宣称交互逐项一致。

待验收：点击/键盘提交与取消、实际焦点归还、外部点击、真实退场重开及事件处理器重入、Owner与锚点生命周期、菜单滚动、打开时主题/数据更新、跨DPI和屏幕边缘、RTL与系统左右手设置、显示中的动画和性能。本次未建立视觉截图基准。
