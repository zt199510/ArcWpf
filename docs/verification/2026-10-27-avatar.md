## 人工测试入口

~~~powershell
dotnet run --project samples/ArcWpf.Gallery -- --page=avatar
~~~

或Gallery→反馈→Avatar：

1. 核对四尺寸、照片圆形裁剪、首字母和在线/离线点，头像不应出现额外焦点框或进入Tab。
2. 连续切换在线/离线/无状态，观察进入与退出、无旧点残留；改姓名、切换照片/首字母。
3. 输入可访问图片地址观察首次下载；输入失效图片地址核对回退。缓存图片应直接出现。HTTP速度受环境影响，程序化测试使用本地可控响应。
4. 切换明暗、Full/Reduced/Off；调整窗口观察页面滚动；在100%/150%/200%DPI核对边缘、文字与点位，读屏只读一份姓名加状态。

真实输入/Tab/滚动、动态观感、多DPI、读屏、高对比度与规模性能未运行，不能标记完整视觉验收。没有Avatar用户通过反馈；收到反馈后按对应版本记录。
