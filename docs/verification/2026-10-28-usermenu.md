## 第三轮重写（Claude，2026-10-28）

用户反馈：前两轮仍“还原不好”。按复刻规则第 3 条停止调参，逐项对照冻结源码与模板部件，前两轮误判原因：

1. 模板中的 `Button` 未覆盖 WPF 默认模板：行、分段与 trigger 仍绘制系统 ButtonChrome（灰色边框、蓝色悬停/按压），与单层 highlight 叠加。之前只改 Background/BorderThickness，默认 chrome 仍在。
2. 调色板缺少 `ArcWpf.Brush.Warning`（及 `Success`），Away 点为透明；Progress 完成色同受影响。
3. 控件 Style 固定 `Width=34/Height=34`，ShowName 时 `Width=150`：40px trigger 被裁剪，姓名长度不同即截断或留白。
4. 图标使用 Unicode 字符（☀☾◐↪⌄●━○），字形与基线随字体回退变化；改为 lucide 矢量路径。
5. 主题切换只加 BorderStrong 描边，缺来源的滑动 thumb；状态切换完全无选中态；行 stagger、退出淡出、chevron 旋转、状态形状过渡、异步退出均缺失。
6. 键盘：Enter/Space 打开不进入首行，指针打开会出现焦点；无 typeahead、Home/End 到切换组时未落到选中项。

修复：重写 `UserMenu.cs` 与 `UserMenuTheme.xaml`（无 chrome 的 ButtonBase 模板、RadioButton 分段 + thumb、PresenceDot 形状/颜色动效、highlight 弹簧滑动与高度同步、Popup 阴影外框与 DPI 正确的上下翻转、退出动画与重开反转、SignOutAsync），补齐调色板令牌，Gallery 改为来源主示例 + 扩展区。
