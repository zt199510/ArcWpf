## 布局与动效证据边界

来源布局、原生映射与具体动效参数见[参考卡](../references/components/ComboBox.md)。外框44/radius18，图标16/gap8；菜单offset8/radius26/padding5，条目36/radius21。Gallery主样本400宽是项目展示选择。artifacts/combobox/gallery.png为最终96 DPI、浅色、720×900窗口约束下的离屏页面，已目视检查初始文字、窄宽、只读和禁用布局；不包含弹出窗口像素，不作为实际窗口截图。

| 动效 | 实现与验证边界 |
|---|---|
| 外框/clear颜色160ms，行80ms | 私有画刷OwnedMotion，保留公共绑定/资源；主题测试通过，中间颜色观感待人工 |
| 菜单进入/退出 | 位移/缩放采样弹簧与淡化，退出保留宿主；真实Dispatcher时钟反向与终态通过 |
| 筛选高度400ms | 内部裁剪宿主高度，原生列表滚动；中间值、恢复及清钟通过 |
| 已选标签240ms、清空160ms | y/blur/opacity；初始blur0和运动终态通过，实际观感待人工 |
| 空态240ms | y4/blur4/opacity；中间帧/清钟通过 |
| clear | .6缩放/blur2/160进入120退出，复用原生操作按钮.96按压；显隐反向通过，实际按压待人工 |
| chevron | 180°/580ms采样；完整等待后清钟通过，实际旋转待人工 |

内部动效属性由OwnedMotion保存持久目标基值，结束清除自有时钟；不覆盖用户SelectedValue/QueryText等绑定。Reduced仅淡化、高度即时，Off即时。弹簧为采样近似，反向不保留速度。40vh采用宿主窗口高度40%；WPF字体、阴影与网页不承诺像素等效。键盘专用焦点框、Up从无活动项到末项、Tab正常导航为桌面适配。
