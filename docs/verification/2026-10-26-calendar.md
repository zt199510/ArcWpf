# Calendar 与 DatePicker 共享样式验证

日期：2026-10-26，未提交工作区。用户要求创建Calendar并由DatePicker使用其样式，保留日历网格和原生输入。按 component-delivery/source-analysis/control-authoring/design-system/ui-verification 流程执行。

## 实现与定位

原截图问题属于内部模板：Popup外框内仍为系统Calendar。新增Arc Calendar/CalendarItem/CalendarDayButton/CalendarButton样式，独立Calendar页面，DatePicker.CalendarStyle共享。保留框架创建的私有Calendar及其BlackoutDates、键盘、选择事件。Today移到标题栏，共享命令检查范围并保留绑定；Clear位于分隔底栏。

渲染检查发现框架初始化内部Calendar.HorizontalAlignment=Left，日历只使用紧凑内容宽度；现设为Stretch，320外框、两侧各16内边距和1边框后实测Calendar宽286 DIP。不是只改Popup的Width。日期圆形用Ellipse，导航沿用项目矢量/1.75描边和圆端规范。
