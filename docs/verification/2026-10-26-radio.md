# RadioButton / RadioGroup 验证（2026-10-26）

状态：实现与程序化验证完成，待用户实际验收。Windows x64，SDK10.0.402，net10.0-windows，Release。未执行实际窗口操作、截图或跨DPI观察，遵循用户此前延期要求。

## 已交付

- WPF原生RadioButton派生：互斥、重复点击保持选择、命令、绑定、SelectionItem自动化、Description；null及三态强制为二态。
- RadioGroup：Header、Items/ItemsSource、SelectedValue默认双向、SelectedValueChanged；唯一内部组名隔离；动态值/项目匹配、方向键循环算法和一次Tab入口。移除容器恢复原GroupName及IsTabStop。
- 模板：17圆环/7圆点、12内边距与文字间距、18行圆角；长标签与说明换行；8行间距、最后无额外尾间距。RadioGroupPanel负责默认竖向布局，无虚拟化。
- 动效：圆点弹簧与淡入/淡出、环按压和预览点、颜色过渡、共享选中框位置及高度；初次和尺寸改变即时放置。Reduced/Off即时；卸载、换模板清理。
- OwnedMotion仅管理内部属性的持久基值和时钟，不改使用方绑定、RenderTransform或共享画刷；同目标不反复重启动画。
- Gallery → RadioButton：官网Review mode同文案/初值，最大380宽；扩展绑定、禁用、长文本、ItemsSource动态添加、RTL与独立GroupName。Consumer同步。

## 差异和未测范围

共享框在WPF透明默认行后；选中行保持透明且取消自己的描边，选中悬停不叠加底色。原CSS允许高亮在所有行底色上、文本下；本实现的跨行移动叠放与选中悬停存在适配差异。独立RadioButton提供选中描边，但没有跨行共享框，完整组效果使用RadioGroup。

禁用、焦点环、组内方向导航及二态约束采用WPF适配；原源API没有独立禁用选项。颜色补间使用WPF通道插值、弹簧使用ControlSpring，不宣称与Web的色彩空间/求解器逐帧一致。系统字体回退仍保留。

实际点击、Space/方向键/Tab焦点、读屏、跨窗口组隔离、100/150/200%DPI、真实动画轨迹/性能、显示中卸载重载与主题切换待验收。本次未建立视觉截图基准，不宣称用户测试通过。
