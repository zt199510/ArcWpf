# Tabs 实现与验证（2026-10-26）

状态：代码及程序化验证完成，等待用户实际窗口验收。环境Windows x64、SDK10.0.402、net10.0-windows、Release。未进行显示窗口的交互观察或截图验收。

## 交付范围

Tabs/TabItem沿用WPF TabControl/TabItem选择、数据绑定、内容模板及自动化。实现顶部水平自动激活、共享选中背景、内容方向过渡与高度动画、标签溢出滚动与边缘渐隐。默认HeaderAlignment=Left，官网主样本显式Center、最大420宽、Overview/Activity/Settings同源文案。

Gallery增加Tabs页，展示高度变化、输入状态保留、禁用、双向SelectedValue绑定、溢出、RTL及嵌套；独立Consumer同步。新增AccentStrong语义资源，保留明暗主题和应用覆盖。

动效复用ControlSpring和OwnedMotion：指示器位置/宽度.42、内容位移及高度.4，淡入240ms/淡出120ms；Reduced只淡化120/100ms，Off立即。完成后内部高度恢复Auto。旧内容采用受限的内存位图（单边4096、总像素800万），不复制活控件、不保存图片、不创建自动化节点；失败则省略退出位图。

## 程序化证据

执行dotnet build ArcWpf.slnx -c Release --no-restore，0警告/0错误。执行dotnet test tests/ArcWpf.Tests -c Release --no-restore，最终全量110项通过，Tabs新增14项。结果artifacts/tests/tabs.trx；专项artifacts/tests/tabs-targeted.trx。

- 原生双向选择绑定、Generated TabItem、SelectedValuePath、删除选择、内容实例及输入文字保留。
- 布局实测标题最小88×36、项间距4、外壳46高/半径18、选中框半径15、内容间距16。
- 独立Tabs选中框隔离；弹簧反向重定向收敛到最新项。
- 导航算法跳过禁用/折叠项、循环/Home/End/RTL；实际键盘焦点尚未测试。
- 有限宽度内长列表溢出、末项自动显露、删除后清理；RTL末项最终坐标位于视口。
- Dispatcher真实动画时钟完成后移除时钟、清理旧位图、当前透明度1；随后再次刷新不闪回。
- Reduced无位移和高度约束；快速重定向、Off、卸载、换模板清理；公开Height绑定和RenderTransform保持。
- 动态主题改变；原生TabControl数据项自动化Peer提供TabItem及SelectionItem（容器包装Peer自身为Custom是WPF正常结构）。
- Gallery页布局与Consumer构造，不显示窗口。

修复测试发现的空选择越界：SelectedIndex=-1时不访问生成器索引，清空/重建标签安全。禁用滚动按钮同时关闭命中，避免透明按钮挡住标签。

旧Debug Gallery运行中占用输出文件；未关闭用户窗口，改用Release构建验证。当前运行的旧窗口不会热更新，需要重新启动Release Gallery查看Tabs。

## 差异与未测

原生字体回退、WPF像素舍入、单层阴影与弹簧求解器仍有平台差异；退出位图不包含Popup/HwndHost。首期仅顶部水平自动激活，未实现垂直、手动激活、forceMount、关闭与拖动重排。

未测：实际鼠标/触摸、Tab/Ctrl+Tab/方向键焦点、读屏、真实窗口快速连续切换、DPI与性能及视觉对照。当前没有已审查WPF截图基准，程序化通过不代表这些专项已通过。
