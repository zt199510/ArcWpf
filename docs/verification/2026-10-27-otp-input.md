## 命令与结果

Windows，SDK 10.0.402，net10.0-windows，Debug。

```powershell
dotnet test tests/ArcWpf.Tests/ArcWpf.Tests.csproj --no-restore --filter FullyQualifiedName~ArcWpf.Tests.OTPInputTests --logger 'trx;LogFileName=otp-input.trx' --results-directory artifacts/otp-input -v quiet
```

最终8/8通过，0失败，持续6秒；结果见artifacts/otp-input/otp-input.trx。编译包括Gallery/Consumer与测试工程依赖，不代表运行其他控件测试。既有CS0067与MSTEST0037警告保留；本次新增控件的同名事件处理器警告已消除。

首轮7/8通过：空模板未触发OnApplyTemplate，旧编辑器事件未解绑，已增加OnTemplateChanged立即清理。离屏检查另发现填充颜色值正确但圆角Border保留旧绘制缓存；对比显式InvalidateVisual前后图确认更新路径，产品改为私有画刷Changed驱动重绘，测试不再主动重绘，保留实际像素断言。暗色导出最初测试Window底色固定白，已让测试页背景跟随主题；不是通过改控件颜色掩盖导出问题。

真实键盘Tab/Shift+Tab、Ctrl+V剪贴板、鼠标选择、多DPI、高对比度、读屏、动态手感及性能未运行。数字模式不接受中文组合输入，不提供字母模式、短信读取、服务器验证码校验或跨格撤销。测试注入路由输入与Pasting事件，不冒充真实按键或剪贴板验收。
