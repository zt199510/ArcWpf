# Popover 实现与验证（2026-10-25）

环境：Windows x64，.NET SDK 10.0.402，net10.0-windows，Release。未执行实际窗口操作、状态截图或跨显示器观察，遵循用户此前延期要求。

## 已实现

- 原生 ContentControl + Popup；IsOpen 默认双向，PlacementTarget、四方向/三对齐、offset6/collision10、ActualSide、IsPresented、Opened/Closed及关闭原因。
- 同Owner单活动层；无效锚点拒绝、卸载/模板替换/Owner关闭释放；退场重开复用宿主，版本号取消陈旧回调。
- 独立屏幕DIP定位，工作区翻转/夹紧，阴影空间与可见面板分离，长内容纵向滚动。
- 数据源、FlowDirection、动效等级显式桥接；默认模板动态主题；输入处理实现Escape、外部左右键及Tab离开。
- 面板192–352宽、padding16、radius26、border1。Full进入透明度160ms/变换580ms、退出160ms；Reduced仅120ms淡化，Off即时。
- Gallery加入Popover页：冻结文档Share样本、含Input的编辑面板、方向/对齐选择、双向绑定、关闭原因。Consumer独立示例同步。

## 已知适配差异

- 浅色CSS双层阴影使用WPF单层DropShadowEffect主阴影，省略3px/10px/.045次层；深色采用主参数。CSS与WPF模糊不能直接视为相同像素。
- 春动效将冻结CSS linear采样映射为WPF关键帧；反向从当前值续接，不承诺速度连续性。
- 极小工作区无侧边空间时允许覆盖锚点以保留内容可达性；临近边缘阴影可能裁剪。
- Gallery使用冻结文档样本，不是官网当前Why this status?主预览的完整复现；当前HTML不含展开内容。
- 原生Popup与跨DPI坐标的最终验收尚未完成，因此本记录是实现及程序化验证完成，不是视觉验收通过。
