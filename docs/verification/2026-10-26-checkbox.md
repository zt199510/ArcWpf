# CheckBox 实现与验证（2026-10-26）

状态：实现与程序化验证完成，待用户测试。环境：Windows x64、SDK 10.0.402、net10.0-windows、Release。本次没有启动可见测试窗口、采集截图或观察实际鼠标/键盘交互。

## 交付范围

- ArcWpf.Controls.CheckBox继承原生CheckBox；Content、Description、bool? IsChecked、可选三态、原生命令/事件/自动化。
- 18×18圆角方框位于44×44区域；标签首行居中对齐、说明同起点、长文本换行、无标签、仅说明、RTL、自定义ContentTemplate。
- 填充弹簧、路径绘制、勾号与横线三点变形、透明度、边框颜色和独立按压反馈；Reduced/Off即时。
- Gallery同源主示例（Include archived projects，初始选中），扩展区提供状态、禁用、三态、命令、长内容、RTL。独立Consumer同步并增加窗口高度。
- 新增ArcWpf.Brush.ControlGlyph，浅色白色、深色OKLCH L=.19，支持资源覆盖；其他现有组件不改用此键。
- 原SwitchSpring移至Motion/ControlSpring供Switch和CheckBox复用，数值算法保持原样。

## 差异与待验收

- 保留WPF三态循环false→true→null→false；二态null下一次到false，与Radix mixed→true不同。
- WPF将标签与说明区都纳入控件点击范围；源站说明文本不负责切换。
- visualDuration .26/.42映射为现有临界阻尼求解器，不保证与Web求解器时间、速度完全一致；按压释放采用CSS spring采样。
- 字体使用现有Windows系统字体回退，Gallery外层沿用项目布局，不声称完整网页逐像素复制。
- 源码没有键盘焦点环样式的完整运行证据；WPF提供围绕44区域的可见焦点提示，属于平台适配。
- 实际点击/Space/访问键/焦点、读屏、100/150/200%DPI、动画流畅度与视觉对照尚待验收。无性能数据，不宣称零分配或固定帧率。

手动入口：Gallery → CheckBox。优先核对主样本外形与文字首行；再切换三态、禁用、明暗主题和动效等级，观察快速连续切换。

## 取消选中闪烁修复（2026-10-26）

用户报告：先选择再取消，“未选中”示例会闪烁，并提供截图。截图只作为静态症状证据；程序化动画时钟测试复现了淡出完成后填充Opacity从目标0回到默认1。

根因：内部PART_Fill/PART_Mark使用SetCurrentValue设置动画基值，动画失效/清除时当前值会被撤销，回到模板默认Opacity=1。修复为由动效引擎对这两个内部部件持久设置Opacity基值；不修改公开控件Opacity、IsChecked或使用方绑定。正常淡出及动画时钟释放保留。

新增UncheckFadeStaysTransparentAfterAnimationCompletes：实际驱动Dispatcher时钟，等淡出完成，检查填充与勾号保持0且无动画时钟；再次刷新后仍为0。修复前失败（实际1），修复后通过。记录分别为artifacts/tests/checkbox-uncheck-before.trx及checkbox-uncheck-after.trx。

全量回归70项通过，见artifacts/tests/checkbox-uncheck-regression.trx。未做实际窗口交互观察，修复后的用户复测待确认。
