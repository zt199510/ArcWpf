## 人工测试入口

在仓库运行：

~~~powershell
dotnet run --project samples/ArcWpf.Gallery -- --page=badge
~~~

或Gallery左侧反馈→Badge（支持导航搜索）。建议依次：

1. 悬停五种色调，核对只有背景/细边框过渡，无点击选中或黑色焦点框；Tab跳过Badge。
2. 点Draft/Live，核对文字与图标、胶囊宽度；快速点击状态/图标按钮验证反向切换、无旧文字回闪或残留空位。
3. 切换Full/Reduced/Off与明暗主题，观察Full位移/模糊/宽度、Reduced淡化/宽度直达、Off直接更新。
4. 调整窗口宽度，检查页面滚动和长文字；在100%/150%/200% DPI核对文字和图标对齐。读屏只读当前状态，复杂内容用显式AutomationProperties.Name。
