# Dialog 实现与验证（2026-10-26）

状态：实现及程序化验证完成，待用户实际窗口验收。Windows x64、SDK10.0.402、net10.0-windows、Release。遵循既定约定，本次未显示测试窗口、采集状态截图或观察实际交互。

## 完成范围

Dialog/DialogHost提供窗口内容区域内的模态对话框。DialogHost包裹背景内容，Dialog作为独立逻辑子节点继承主题、DataContext和动效等级。支持直接声明Host.Dialog和双向IsOpen绑定，或Dialog.Show(origin)寻找祖先Host；CloseCommand、关闭按钮、Escape及遮罩关闭，经Closing可取消。替换、卸载和换模板强制清理；Content不重建，输入状态保留。

默认模板实现最大440宽/16留白、34圆角、24内边距、标题18和说明14、分隔线、32关闭按钮和16矢量叉。长内容整体滚动。Host内部背景Presenter承担BlurEffect7及输入阻断，不覆写使用方内容Effect/IsEnabled绑定。新增DialogOverlay与DialogClose两个语义画刷，不改变已有资源值。

面板进入160ms淡入、.4弹簧采样位移/缩放，遮罩240ms；退出160ms。Reduced120ms淡化，Off立即。标题/说明双层位移、模糊及淡化，退场旧层不产生Peer。内部OwnedMotion保存持久基值；重开取消旧完成回调。关闭按钮复用Arc Button的32尺寸.96按压、释放和颜色过渡。

Gallery增加Dialog页面，并在窗口根部加入DialogHost，覆盖整个窗口内容区域。主示例使用Review changes / Publish workspace原文；Keep editing与Publish now仅关闭，不执行任何外部发布。扩展示例包含表单状态保留、标题说明切换、长内容和可取消关闭。Consumer同步独立接入。

## 适配差异及待验收

这是DialogHost范围内模态，不是OS级Window.ShowDialog，不阻止标题栏和其他窗口。退出期间继续阻止背景点击，与原版退出点击穿透不同；支持绑定/程序重开。每Host同时一个Dialog，替换会强制结束旧项；暂不实现堆叠、非模态、拖动调整大小。

系统字体、单层阴影、BlurEffect及弹簧采样与Web存在差异。HwndHost和独立Popup不保证参与背景模糊；已有浮层建议先关闭，Dialog内部Select/Popover组合需实际验收。未声明高对比度或读屏全量支持。

待验收步骤：打开官网样本检查尺寸/居中；按Tab/Shift+Tab确认不进入背景，Escape关闭后确认焦点回到触发按钮；点击面板不关闭、点击遮罩关闭；表单中文输入/撤销及再次打开保留；快速开关和文案切换；关闭保护；缩小窗口及长内容滚动；明暗主题/Full/Reduced/Off；100/150/200% DPI与系统窗口关闭。未建立已审查WPF截图基准，性能未测量。

退场重复关闭已纳入时钟回归：连续Close不会使完成回调失效，最终仍释放遮罩。
