# AvatarUpload

状态：WPF 基础视觉与输入层已完成，已完成构建与 Gallery 启动检查；真实窗口拖放、主题和 DPI 仍待人工验收。

来源：Arc Pro 页面公开资料；Registry 返回 404，无 Pro 源码复用。当前为独立 WPF 实现，提供圆形头像/首字母回退、悬停相机层、图片选择、拖放、Enter/Space 触发、大小限制、上传进度环/错误提示和 `FileSelected` 事件。新增 `Hint`、`Accept`、`MaxSize`、`Size` 属性。

与 Arc Pro 的差异：Pro 的圆形裁剪工作区、拖拽定位、缩放/捏合、输出图片编码、上传取消/重试和成功收口动效没有可用源码，当前保留为后续扩展；WPF 版本先在选图后直接显示原图，并把这些差异明确保留为未实现。
