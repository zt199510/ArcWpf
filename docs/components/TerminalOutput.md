## 这是显示控件，不是终端

- 控件不运行任何东西。宿主启动进程，把输出传给 `Write`，再设置 `Status`。
- 它给人看，**不是原始日志**：`\r` 覆盖后旧内容不再存在，`GetText()` 和复制得到的是屏幕上的文字。需要原始字节的宿主要自己保存。
- 不实现清屏和光标定位（`J`、`H` 等）：程序无法擦掉之前的输出记录。用到这些或备用屏幕时显示提示，说明内容可能错乱。

## 输出是不可信内容

- 不可见字符和双向控制符显示为 `[U+202E]` 这样的标记，用警告色，和 DiffView 相同。
- 其它控制字符丢弃。窗口标题、超链接等 OSC/DCS 序列去掉，只留文字；链接不可点击。
- 未结束的转义序列有长度上限（CSI 256，字符串类 65536），超过后恢复显示，不会吞掉后面的输出。
- 单行上限 16000 字符，超出部分计数并写在行尾。样式表上限 4096，超出的文字保留内容、失去颜色。

## 上限与丢弃

没有任何数据是静默丢掉的，都有提示：

| 情况 | 行为 | 提示 |
|---|---|---|
| 超过 `MaxLines` | 超出 10% 时删最旧的行 | `Earlier output is gone: N lines…` |
| 积压超过 8M 字符 | 丢弃积压中最旧的部分，保留 4M | `Output came faster than it could be shown…` |
| 使用全屏控制 | 只显示文字 | `This program draws to a full terminal screen…` |

每 33 ms 处理一次，每次最多 256K 字符，优先级低于输入。没有输出时定时器停止，不占 CPU。

## 跟随

- 默认跟随最新行。向上滚动（滚轮、键盘、滚动条）后停止跟随，显示 “Jump to latest” 按钮；回到底部或点按钮后恢复。
- 不跟随时，新行不移动正在看的内容；删除旧行时位置随之调整，**看的还是同一段文字**。
- 这段文字本身被淘汰后，视图停在保留范围的最旧一行，内容随淘汰前进。输出远快于保留上限时（如每秒几万行、保留 1 万行）不到一秒就会发生。要长时间回看，宿主应调大 `MaxLines`。

## WPF 公开契约

`TerminalOutput : Control`，`TerminalStatus { Idle, Running, Succeeded, Failed, Stopped }`。

| 属性 | 类型/默认 | 说明 |
|---|---|---|
| `Command` | `string`，空 | 标题栏显示的命令行 |
| `Status` | `Idle` | 进入 `Running` 开始计时；结束状态会立刻显示已写入的全部内容 |
| `ExitCode` | `int?` | `Failed` 时显示 `Exit N` |
| `CanStop` | true | 运行时是否显示停止按钮 |
| `MaxLines` | 10000 | 必须大于 0 |
| `MaxBodyHeight` | ∞ | 父容器不限高时最高 320，否则虚拟化失效 |
| `EmptyText` | `No output` | 运行中显示 `Waiting for output…` |
| `IsFollowing` | 只读 | 是否跟随最新行 |

方法：`Write`、`WriteLine`（任意线程）；`Flush`、`Clear`、`GetText`（UI 线程）。事件 `StopRequested`：只发出请求，控件不改状态，由宿主停止进程后设置 `Status`。

键盘：上下移动选中，Ctrl+C 复制选中行，左右键和 Shift+滚轮横向滚动。列表到头后滚轮交给外层。

## 视觉

- 颜色令牌 `TerminalAnsi0..15`，按主题定义。深色下“黑”提亮，浅色下“白”压暗，避免默认底上看不见。
- 程序指定了背景色时，前景对比度低于 3:1 则改用黑或白，让 `30;42m` 这类徽标可读。
- 256 色和真彩色按程序给的值显示。程序指定的颜色在该主题下可能偏暗，不做校正。
- 粗体用 SemiBold，暗淡用透明度。不换行，长行横向滚动。

## 结构

`TerminalBuffer`（内部，无 WPF 依赖）负责解析和行存储；`DrawnRowList`/`DrawnRowItem` 是和 DiffView 共用的虚拟化绘制列表。缓存按行版本和主题版本失效。
